# CameraPhotoTools（Vibe coding）

## 相机拍摄照片后的一些处理小工具
目前仅有windows版
#### raw
目前包含cr2,cr3,nef,nrw,arw,srf,sr2,dng,erf,mef,mos,orf,pef,ptx,pxn,raf,raw,rw2,rwl,srw,x3f,3fr,fff,eip,bay。
欢迎补充
#### jpg
包含.jpg和.jpeg

## 功能
1. 查找指定目录下的jpg对应指定目录下的raw，不存在对应的raw则删除
2. 查找指定目录下的raw对应指定目录下的jpg，不存在对应的jpg则删除
3. 批量对目录下的jpg文件重命名
4. 竖向拼接一组延时照片。达到时间切片的效果。
   > 此项功能核心来源于小红书用户@蹑手蹑脚的西红柿。把他的代码喂给了ai得到此项功能。十分感谢他
5. 径向拼接一组延时照片。达到时间切片的效果。
